## 8. 주요 인사이트

### Challenger
- 전체 구매 유저의 29.8%, 평균 GMV ₩650만
- 74%가 실제 당첨 이력 → 로직 유효성 검증됨
- 평균 미접속 80일 → 비교적 활성 유저
- ATEEZ 팬이 가장 많음

### Collector
- 전체 구매 유저의 21.9%
- 평균 GMV ₩32만 — Challenger의 1/20 수준
- 포카 수집 목적 → 단가 낮은 상품 중심

### Beginner
- 전체 구매 유저의 45.6%
- 평균 미접속 208일 — 이탈 위험군 다수 포함
- 평균 GMV ₩138만 — Collector보다 높음 (분류 불가 고액 구매자 포함)
